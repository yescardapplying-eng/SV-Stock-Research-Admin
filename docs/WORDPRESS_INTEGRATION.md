# WordPress Integration Guide (WPForms 1.9.1.4 Compatibility)

## Background & Compatibility

The live site `svstockresearch.in` runs **WPForms 1.9.1.4**.
In this version, entry data is stored in the database tables:
- `{$wpdb->prefix}wpforms_entries`
- `{$wpdb->prefix}wpforms_entry_fields`

The SV Stock CRM Bridge plugin interacts with WPForms using documented action hooks and direct read-only SQL queries via `$wpdb->prepare()`.

## Hook Implementation: New Submissions

The plugin attaches to:
```php
add_action('wpforms_process_complete', [$this, 'on_wpforms_process_complete'], 10, 4);
```
Arguments received:
1. `$fields`: Sanitized submitted field key-values.
2. `$entry`: Entry details.
3. `$form_data`: Complete form schema and title.
4. `$entry_id`: Entry ID generated by WPForms.

## The Outbox Pattern

To ensure customer form submissions are never blocked or slowed down:
1. When `wpforms_process_complete` fires, an outbox entry is written to `wp_sv_stock_crm_outbox`.
2. A single non-blocking event `sv_stock_crm_dispatch_outbox_cron` is scheduled immediately.
3. An hourly/minutely recurring cron serves as a fallback.
4. The dispatcher sends an HTTP POST request to Render with HMAC-SHA256 headers.

## Historical Entry Export Endpoint

Endpoint: `GET /wp-json/sv-stock-crm/v1/entries`
Parameters supported:
- `form_id`: Filter by specific form ID.
- `limit`: Number of entries per batch (max 100).
- `cursor`: Starting `entry_id` cursor for sequential batch pagination.

Security: Requires HMAC-SHA256 signature matching `SV_STOCK_CRM_PULL_SECRET`.
